ROADBOOK v0.4 — первая рабочая версия iPhone

Уже работает:
- мобильный интерфейс;
- заправка;
- расходы;
- остановки;
- заметки;
- локальное сохранение в браузере;
- ввод без интернета после первого открытия;
- переход к Яндекс Картам;
- журнал последних записей.

Пока НЕ подключены:
- синхронизация с Google Sheets;
- полноценная офлайн-карта;
- автоматическое определение местоположения.

Для установки как PWA нужен HTTPS-хостинг. Следующим шагом разместим эти файлы и добавим Service Worker, чтобы приложение действительно запускалось офлайн после установки.
